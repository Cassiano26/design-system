# Design System with Storybook and React

## Overview
This repository contains a scalable and customizable Design System built using **React** and **Storybook**. The goal is to provide a unified set of UI components and guidelines to ensure consistent and efficient development across projects.

## Features
- 📚 **Storybook Integration**: Interactive documentation and sandbox environment for components.
- 🎨 **Customizable**: Easily extend or customize components to fit specific branding needs.
- 🧱 **Reusable Components**: Modular and reusable components designed for scalability.
- 🧪 **Tested and Accessible**: Built with accessibility and testing in mind.

## Getting Started

### Prerequisites
To use and develop the Design System, ensure you have the following installed:
- [Node.js](https://nodejs.org/) (>= 16.x)
- [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/)

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/Cassiano26/design-system.git
   cd design-system
   ```

2. Install dependencies:
   ```bash
   npm install
   # or
   yarn install
   ```

3. Start Storybook:
   ```bash
   npm run storybook
   # or
   yarn storybook
   ```

## Scripts
| Command              | Description                                |
|----------------------|--------------------------------------------|
| `npm run storybook`  | Start the Storybook server                |
| `npm run build`      | Build the Design System for production    |
| `npm run test`       | Run tests                                 |
| `npm run lint`       | Lint code using ESLint                    |
